

\# FDE Business Reporting Project



\## About

This is my Day 11 Forward Deployed Engineer training project.



It uses Python, SQLite and SQL to generate business reports and analyze customer revenue.



\## Features

\- Total Customer Analysis

\- Total Orders Analysis

\- Total Revenue Calculation

\- Average Order Value

\- Customer-wise Revenue Report

\- High Value Customer Analysis

\- Minimum and Maximum Order Analysis

\- CSV Report Export



\## Technologies Used

\- Python

\- SQLite

\- SQL

\- CSV

\- Git

\- GitHub



\## Project Files

\- business\_report.py

\- customer\_revenue.csv



\## How to Run



1\. Install Python.

2\. Open PowerShell in the project folder.

3\. Run:



```bash

python business\_report.py

```



\## Learning Outcome

Learned Python database integration, SQL aggregation, GROUP BY, HAVING, JOIN, parameterized queries and GitHub version control.
